Privacy controls

Collection is off by default. This dashboard never enables collection or changes browser permissions.

Fixed consent status

Only the listed NEXUS tools and adapters can appear here. This is configuration status, not a history of browser or desktop activity.

Native host

The native host is unregistered until you explicitly register it.

Registration is an explicit, browser-specific action. It validates the extension ID and host path, then writes only that browser’s native-host manifest. It does not turn on collection or request browser access.

Platform notes

On Linux, tray visibility depends on the desktop environment; use the application launcher to open this dashboard if no top-bar icon is available. On macOS, this is a menu-bar shell and not a signed or notarized distribution.
