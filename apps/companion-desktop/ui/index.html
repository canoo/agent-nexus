Privacy & collection controls

Collection is off by default and requires at least one granted browser tool consent before it can be resumed. Opening this dashboard never enables collection or alters permissions.

Local data controls

Shortening retention removes expired spans immediately. Retaining 0 days keeps no raw history. Pruning removes expired spans now based on the configured retention window. Clearing history deletes recorded activity while preserving collection state, tool consent, and MCP/project memory.

Tool consent & privacy disclosure

Privacy disclosure: NEXUS Companion observes only fixed tool presence, surface (active browser tab), and start/end timestamps. The browser extension checks the selected tab’s origin locally to identify a supported tool. It never sends or stores page URLs, titles, prompts, responses, or browsing history. Browser permission is granted separately in the extension.

Granting or revoking consent per tool updates your settings immediately without enabling collection. Desktop foreground adapter consent is not implemented and is read-only.

Native host

The native host is unregistered until you explicitly register it.

Registration is an explicit, browser-specific action. It validates the extension ID and host path, then writes only that browser’s native-host manifest. It does not turn on collection or request browser access.

Platform notes

On Linux, tray visibility depends on the desktop environment; use the application launcher to open this dashboard if no top-bar icon is available. On macOS, this is a menu-bar shell and not a signed or notarized distribution.
