# Bundled identity assets

claude.svg, gemini.svg (googlegemini), chatgpt.svg (openai), copilot.svg
(githubcopilot), perplexity.svg and ollama.svg are copied unchanged from
`docs/assets/tools/` in this repository. See its SOURCES.md for original
Simple Icons provenance. LICENSE-simple-icons.md is bundled alongside them.

Ollama identifies the local runtime for Qwen/Llama model names, with the exact
model as supplementary text and a runtime tooltip. model.svg is an original
neutral unknown-identity glyph, not a provider or model logo.
