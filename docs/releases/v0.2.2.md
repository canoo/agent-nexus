# NEXUS v0.2.2

Released October 6, 2026. [GitHub release](https://github.com/canoo/agent-nexus/releases/tag/v0.2.2).

## Highlights

- **Stability sprint:** fixed the TUI configuration crash, self-update,
  installer completion, and dependency automation.
- **SQLite-only Task Log:** the MCP store records task costs, byte counts,
  hashes, and model/provider metadata. The TUI reads SQLite directly; the
  JSONL write path is gone. Existing JSONL history is imported once at startup.
- **Fresh installs:** Claude Code loads the NEXUS orchestrator and the MCP
  server starts with its npm dependencies installed, thanks to @blakesaunders
  ([#111](https://github.com/canoo/agent-nexus/pull/111)).
- **Current toolchain:** Go 1.27.1, MCP SDK 1.32.1, GitHub Actions off Node 20,
  and zero `npm audit` vulnerabilities.

## Fixed

- `configureMCP` no longer panics on a null MCP configuration ([#114](https://github.com/canoo/agent-nexus/issues/114)).
- TUI self-update now checks an `install.sh` checksum that the release actually
  publishes.
- `install.sh` installs MCP npm dependencies; `setup-nexus.sh` embeds the real
  version so update checks work.
- MCP configuration writers share a merger that preserves unowned fields.
- Dependency automation has the permissions needed to push updates.

## Security and upgrade notes

- The MCP SDK update resolves the critical `proxy-addr` advisory. Go 1.27.1
  replaces a toolchain with known standard-library CVEs.
- Installers now require Node.js **22.13+** and git before starting.
- On first start after upgrade, the MCP server imports any legacy JSONL task
  history into SQLite once. The import is idempotent and cannot block startup.
  No manual migration is needed.
