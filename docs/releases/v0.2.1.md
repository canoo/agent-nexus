# v0.2.1 Release Notes — Draft

> **Status:** Draft. Do not publish this file, a GitHub Release, or community
> copy until the v0.2.1 release gates in [Release Process](../release-process.md)
> have passed.

## Highlights

- **Local observability foundation:** NEXUS now dual-writes safe MCP routing
  metadata to SQLite and the existing JSONL compatibility log. Existing JSONL
  history can be imported locally and idempotently.
- **Usage & Cost Dashboard:** an optional Tokscale integration displays CLI
  usage and cost aggregates alongside—never merged with—NEXUS-native local
  routing savings.
- **Health and retention guidance:** the TUI detects optional Tokscale safely
  and warns when NEXUS's configured Claude session-history guidance is below
  30 days.

## Thanks, Tokscale

NEXUS v0.2.1 builds on the excellent upstream work from
[Tokscale](https://github.com/junhoyeo/tokscale) by Junhoyeo and contributors.
Tokscale provides the local CLI usage and pricing aggregates used by this
optional adapter. NEXUS keeps that information distinct from its own routing,
local-latency, and savings metrics.

## Upgrade notes

- The MCP server now requires Node.js **22.13 or newer** because NEXUS uses the
  built-in `node:sqlite` API.
- Tokscale remains optional. Install it separately (for example,
  `bunx tokscale@latest`) to populate CLI usage data.
- NEXUS does not collect raw prompts, responses, URLs, source code, titles, or
  arbitrary provider output. Provider failures are stored only as fixed safe
  categories.
