## Remaining limits and recommendation

Adoption conservatively imports supported project-wide instructions and reports
non-equivalent settings/scoped rules. It does not perform model-assisted semantic
merging or interactive policy-conflict resolution. Original instruction text is
preserved, so users must review repeated or contradictory instructions. The
global setup script has not been migrated to the project AGENTS projection model.

Routing has a short failure cooldown, not learned model ranking or a durable
cloud-rate-limit prompt queue. Live Ollama execution and live tool loading are
unverified. Persona installation preserves upstream Markdown; it does not certify
harness-specific skill loading or translate tool permissions. Registry reads are
not pinned as one cross-file release snapshot.

Compatibility refresh is explicit (`compat update`, `update --compat`, or TUI
`u`), not automatic with binary self-update. Its official main-branch catalog URL
may return 404 until the catalog is separately approved for main; live refresh
was not verified. No tested vendor range was invented.
